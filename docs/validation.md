## 范围和限制

所有安装、迁移和恢复测试在临时副本运行，未启动真实模型会话或调用模型 API。
本机现有旧名安装由用户此前安装；0.3.0 的桌面实际升级需要用户关闭 ZCode 后运行安装器。
旧工作区专属配置不会自动扫描改写，升级后需在原版 UI 为新名称重新配置。

当前桥接范围仍为 Windows 普通本地主会话；子代理、工作流、远程 Agent、标题和摘要
专用请求未覆盖。解析 active 不等于供应商最终接收请求的抓包证据。

# zcode-unrestricted 系统提示词替换

适用于带 ZCode Unrestricted 桥接补丁的原版 Windows Desktop ZCode。普通插件 Hook 没有
system 替换接口，因此只导入这个目录、没有安装宿主补丁时不会生效。

启用/禁用使用原版设置中的插件开关，没有额外的启用状态。项目级配置优先于
用户配置；用户级关闭后，项目若显式开启仍按项目设置执行。

默认正文在用户插件 data 目录的 `system.md`。插件高级配置的 `promptFile`
可选择另一 UTF-8 文件；相对路径以初始工作区解析。正文上限 256 KiB。
每轮开始时读取；工具往返和重试固定本轮快照，下一轮才应用修改。

配置入口是原版插件详情里的“高级信息 → 配置 → 系统提示词文件”。
该输入框填写**文件路径，不是提示词正文**；输入后点击“保存配置”，开启插件并发送下一轮。
路径建议使用绝对路径，直接填一行，不加引号、`@` 或 JSON。
选择用户范围可设置默认值，工作区的显式配置会覆盖用户值。

例如使用开发目录中的候选提示词：

```text
D:\Work\Zcode\zcode-unrestricted\docs\test.md
```

留空并保存会使用安装后的默认正文。交付包的 `edit-prompt.cmd` 始终打开默认正文，
不会打开上述选定的自定义文件。修改开发包的提示词模板也不会覆盖已存在的默认正文。

`status.cmd` 的 `mounted` 表示磁盘补丁校验通过；`lastTurn.state=active` 表示最近一轮
成功解析正文。检查记录的工作区和时间。状态输出的 `promptFile` 指默认文件位置，
不代表高级配置选中的有效文件。

关闭、文件读取失败或正文无效时恢复原生基线。桥接只覆盖普通本地主会话的
system 前缀，子代理、工作流和专用摘要/标题请求仍由原版处理。

卸载宿主补丁请使用交付包的 `uninstall.cmd`。原版 UI 中禁用即可停止覆盖；
从 UI 删除注册/目录也会停止覆盖，但 UI 本身不负责恢复 Agent 补丁。
